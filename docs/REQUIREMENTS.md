# 需求审查与 MVP 边界

## 审查结论

原技术栈基本合理，无需 Redis、Celery 或微服务。15 天完成带真实故障测试的可演示 MVP
可作为计划，但同时交付生产级权限、大规模扫描优化、任意 HDF5 自动识别、模型训练、
复杂标注协作与高可用运维不现实。验收以数据正确性与完整链路为先，不承诺未测试的吞吐量。

需求中有四处需要明确解释：

1. “文件不复制”和“历史实验可复现”依赖采集存储的不可变约定。数据库快照无法阻止宿主机
   改写磁盘文件。MVP 采用完成标记 + 只读服务挂载 + 完整 SHA-256 校验，发现变化后阻断处理、
   发布或导出并报告源损坏。真正防止宿主机管理员改写需存储快照/WORM/内容寻址归档，暂缓。
2. 大文件快速扫描与严格内容判重有成本冲突。大小和 mtime 只能用于候选过滤。
   MVP 每次接入扫描均对完成候选文件流式计算完整哈希，包括已经登记的路径；
   扫描范围应由批次/子目录限制。后续快速扫描须明确标记“仅元数据检查”，不混同完整复查。
   同一路径相同内容和解释参数去重，跨路径相同内容暂不合并，只提供校验值索引。
3. “至少一次执行”允许重复计算；通过执行令牌和唯一约束只发布一次逻辑结果，
   不宣称 exactly-once。领取事务不能覆盖整个计算时长。
4. Manifest 无须在 MVP 中预写磁盘。发布事务保存固定成员与规范 JSON 文本及其哈希；
   下载直接返回这些字节。由此避免 PostgreSQL 与文件系统的跨资源原子性问题。

这些约定不阻碍阶段一。阶段二开始前最需要确认的是采集端能否提供 `.done` 标记，
以及真实 BIN dtype/端序和 HDF5 dataset 布局；没有样例时默认使用下列显式协议和合成数据。

## 默认输入协议（阶段二已实现）

- 一台 Linux 文件存储主机；API/Worker 看到同一个受控根目录。客户端仅传相对路径或根目录别名，
  不接受任意绝对路径。根目录通过运维配置给定。
- 采集端先写 `.part`，关闭并原子重命名为 `.bin` / `.h5`，最后原子创建同名 `.done`。
  扫描器只接收有完成标记的文件；不能仅用“连续两次大小不变”宣称已完成。
- BIN 必须显式提供 `sample_rate_hz > 0`、`center_frequency_hz >= 0`、
  `dtype ∈ {int16,float32}`、`byte_order ∈ {little,big}`、交织顺序 IQ。
  文件字节数须整除每个复数采样的字节数。
- HDF5 初版显式指定 dataset 路径，支持一维 complex64 和二维 `[N,2]` 数值数组；
  不推断任意实验室私有布局，不允许外部链接与外部存储绕过受控根目录。
- 不提供原始文件上传；不训练模型；没有权重时采用明确标识的确定性 MockModel。
- 标签先采用固定可配置枚举及 UNKNOWN；UNKNOWN 是人工结论，不能等同尚未审核。

阶段二通过 `文件名.iq.json` 提供显式元数据，使用 `文件名.done` 标记完成。
阶段二同步 CLI 已在阶段三改为队列提交；异步 HTTP 扫描、分段与质量检查现已启用。
模型和标签仍未实现。协议细节与完整性边界见 PHASE_2.md。

## MVP 功能清单及验收

当前阶段一至五核心MVP已实现；实际交付和限制见PHASE_5.md。
真实模型权重与精度验证仍待输入，Mock 结果不代表真实识别。

| 阶段 | 交付范围 | 关键验收 | 建议时间 |
|---|---|---|---|
| 一 | 架构、ER、状态机、环境、迁移、健康 API | 真 PostgreSQL 迁移、健康与最小测试 | 第 1–2 天 |
| 二 | 完成文件扫描、指纹、BIN/HDF5 reader、区间索引及查询 | 重扫不重复、变更检出、元数据及路径防护 | 第 3–5 天 |
| 三 | DB 队列、分段/质量任务、多 Worker、租约、恢复与幂等 | 竞争领取、强杀进程、旧执行拦截、有限重试 | 第 6–9 天 |
| 四 | Mock/PyTorch 适配、预测、审核与基础 Vue 审核页 | 真实 IQ 到预测到审核、409 冲突与审计 | 第 10–12 天 |
| 五 | 筛选、不可变发布、Manifest、其余两个页面、联调 | 完整链路与历史版本不变 | 第 13–15 天 |

15 天是实现预算，含代码审查的节奏需按你的反馈调整。若进度不足，先缩小 UI 装饰、
模型种类、复杂筛选；并发/故障/快照正确性测试不得删掉。

MVP 的有界处理约定：扫描任务至多 100 路径；每个分段任务默认最多提交 1,000 个片段，
长文件需调用者手动按确定性区间拆任务，超限请求会拒绝；
一次发布先限制 10,000 个成员，预览上限 2,048 点。这些是初始容量保护值，后续通过测试再调整，
不是性能承诺。扫描和哈希必须在后台执行，HTTP 仅提交任务。

## 暂不实现

分布式对象存储、多租户、SSO、自动模型训练、复杂雷达算法、实时流处理、取消/抢占任务、
自动迁移多分支、高可用数据库、任意大小数据集事务发布。阶段一也不提前生成业务模块空壳或假 API。
